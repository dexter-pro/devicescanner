# Device Scanner

Herramienta desarrollada en Python para realizar tareas de reconocimiento de dispositivos y análisis de servicios disponibles en una red.

El proyecto fue creado como ejercicio práctico para aplicar conceptos de programación, redes y automatización dentro del área de ciberseguridad.

## Características

- Escaneo de dispositivos.
- Identificación de puertos.
- Registro de resultados.
- Automatización de determinadas notificaciones.
- Uso de Python para procesamiento de información de red.

## Tecnologías utilizadas

- Python
- TCP/IP
- Sockets
- Automatización
- SMTP

## Requisitos

Para ejecutar el proyecto es necesario contar con:

- Python 3
- pip
- Acceso autorizado a la red que se desea analizar
