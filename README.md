# Device Scanner

Device Scanner es una herramienta desarrollada en Python con fines educativos para aplicar conceptos de programación, redes y ciberseguridad.

El proyecto permite realizar tareas relacionadas con el reconocimiento de dispositivos y servicios disponibles dentro de una red, utilizando diferentes scripts para el análisis de puertos y automatización de procesos.

## Objetivo del proyecto

El objetivo principal de este proyecto es poner en práctica conceptos relacionados con:

- Programación en Python
- Redes TCP/IP
- Escaneo de dispositivos
- Análisis de puertos
- Automatización
- Manejo de información obtenida durante un análisis de red

Este proyecto fue desarrollado como parte de mi formación académica en el área de ciberseguridad.

## Características

El repositorio contiene diferentes componentes utilizados para realizar tareas como:

- Escaneo de dispositivos dentro de una red.
- Identificación de puertos y servicios.
- Procesamiento de información obtenida durante el escaneo.
- Automatización de diferentes tareas.
- Envío de información mediante correo electrónico.
- Manejo de archivos y resultados generados por la aplicación.

## Tecnologías utilizadas

- Python 3
- Redes TCP/IP
- Sockets
- SMTP
- Scripting
- Automatización

## Requisitos

Para ejecutar el proyecto es necesario contar con:

- Python 3 instalado.
- pip para la instalación de dependencias.
- Conexión a la red que se desea analizar.
- Autorización para realizar pruebas sobre los dispositivos analizados.

Puedes verificar la versión instalada de Python con:

```bash
python --version
```

También puede utilizarse:

```bash
python3 --version
```

## Instalación

Primero se debe clonar el repositorio desde GitHub:

```bash
git clone https://github.com/dexter-pro/devicescanner.git
```

Después, ingresar al directorio del proyecto:

```bash
cd devicescanner
```

En caso de que el proyecto utilice dependencias externas y exista un archivo `requirements.txt`, pueden instalarse utilizando:

```bash
pip install -r requirements.txt
```

## Ejecución

Para iniciar la herramienta se debe ejecutar el archivo principal del proyecto:

```bash
python scanner.py
```

Dependiendo de la configuración del sistema, también puede ser necesario utilizar:

```bash
python3 scanner.py
```

Una vez iniciado el programa, se deberán proporcionar los parámetros solicitados por la aplicación para realizar el análisis correspondiente.

## Funcionamiento general

El funcionamiento de Device Scanner puede resumirse en los siguientes pasos:

1. Se ejecuta el programa principal.
2. El usuario proporciona los parámetros necesarios para realizar el análisis.
3. La aplicación procesa la información de red.
4. Se realizan las funciones correspondientes de escaneo.
5. Se identifican dispositivos, puertos o servicios disponibles.
6. Los resultados obtenidos son procesados por los diferentes módulos del proyecto.
